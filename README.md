# MEML v6.9: Модель единого мирового листа в 6 измерениях

Шестимерная модель идентичности частиц без струн, без GUT и без суперсимметрии.

## Ключевой результат

Модель **численно предсказывает** реликтовую плотность тёмной материи:

| Величина | MEML v6.9 | Planck 2018 | Отклонение |
|---|---|---|---|
| Ω_DM h² | **0.1188** | 0.120 ± 0.001 | **~1%** |

## Что решает модель

- **Квантование заряда** выведено из топологии π₁(T²/Z₃) = Z² ⋊ Z₃
- **Безмассовый 4D-гравитон** удержан триполем (без тахиона и духов)
- **6D-аномалии** сокращены через дуальную фазу «нч» (без новых сущностей)
- **Киральность** возникает автоматически из Z₃-проекции
- **Три поколения** из трёх неподвижных точек Z₃
- **УФ-полнота** через асимптотическую безопасность
- **Тёмная материя** — стерильное нейтрино ν_R с m_s = 7.1 кэВ

## Воспроизведение

```bash
git clone https://github.com/kolbasa1972/meml-v6.9.git
cd meml-v6.9/sterile-dm
gfortran -O2 -std=legacy -fallow-argument-mismatch -o sterile-nu.exe \
    src/*.f90 src/*.f
./sterile-nu.exe params.ini > ../data/output_T_evolution.dat
```
